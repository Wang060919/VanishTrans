# VanishTrans 原生 smoke 测试清单

> 每次发布候选（RC）都必须在本机 Windows 上完整执行并签收。
> 前置：`pnpm install`、`pnpm check`、`pnpm check:rust`、`pnpm tauri build` 全部通过。

## 安装与启动

- [ ] NSIS 安装包生成于 `src-tauri/target/release/bundle/nsis/`
- [ ] 全新安装后可从开始菜单启动，托盘图标出现
- [ ] 关闭并重新启动后悬浮球位置、主题、快捷键配置保持
- [ ] 二次安装覆盖升级不丢失历史与 TM 数据

## 划词翻译 Alt+Q

- [ ] 在浏览器/编辑器选中英文，Alt+Q 弹出翻译结果
- [ ] 翻译后用户剪贴板内容保持不变
- [ ] 无 API Key 时提示可操作的错误，不静默失败

## 原地替换 Alt+R

- [ ] 选中文本后 Alt+R，文本被替换为译文，剪贴板内容恢复
- [ ] API 等待期间切换前台窗口，不会粘贴到新窗口（显示失败提示）
- [ ] 替换失败（如写入剪贴板失败）不覆盖选中文本

## 截图 OCR Alt+W

- [ ] 截屏后可拖选区域，识别文字并翻译
- [ ] Esc 可取消截图，覆盖层不残留
- [ ] 截图加载失败时显示可点击重试的错误状态
- [ ] 识别到空文字时提示重试而非卡死

## 剪贴板监听

- [ ] 开启后复制文本自动翻译（窗口未聚焦时 2s 内响应）
- [ ] 关闭后复制文本不再触发翻译，重新开启恢复正常

## 设置与数据

- [ ] 修改 Base URL/Model/API Key 后保存并生效
- [ ] 修改快捷键立即生效，冲突项在前端提示且不拖垮其他快捷键
- [ ] 术语表编辑后立即关闭设置面板，重新打开数据仍在
- [ ] 历史可搜索、删除、清空，重启后保留
- [ ] TM 可导入/导出 CSV，含 `=` 前缀文本不会触发公式
- [ ] 修改模型/服务后 TM 不返回旧配置的缓存结果

## 稳定性

- [ ] 连续翻译 20 条文本无卡顿、无内存持续增长
- [ ] 托盘退出时历史已落盘（重新启动可见最近记录）
- [ ] 日志文件 `%APPDATA%` 下正常写入且不包含 OCR 原文
