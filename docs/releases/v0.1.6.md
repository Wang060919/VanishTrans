# VanishTrans v0.1.6

## 更新内容

- 简化悬浮岛交互：译文就绪后点击主体直达结果，`⋯` 入口常驻可见，便于打开快捷操作。闲置与译文就绪胶囊加宽至 148 像素；失焦收起时保留结果，点击 `X` 清除岛上的结果。
- 从悬浮岛任一“主界面”入口打开已完成译文时，保留原文、译文与翻译方向；再次打开同一结果不会覆盖工作区内的编辑。
- 新增“展开阅读 / 返回编辑”，方便阅读长译文；返回编辑时保留输入选区、焦点与译文滚动位置，修复视图展开后滚动范围变化导致的位置丢失。
- 划词翻译弹窗内按 `Esc` 或点击 `×`，会取消当前翻译并关闭；迟到的响应不会恢复已取消的结果。
- 改进 DPI 与窗口尺寸变化时的悬浮岛裁剪，按当前窗口倍率重建区域，保留停靠边缘形状，避免累计缩放误差。
- 悬浮岛拖至工作区边缘后自动吸附，并显示对应的停靠外观。
- 截图 OCR 可先确认、编辑识别文字，再点击“翻译”或按 `Ctrl+Enter`。改进 `Esc` 取消和截图窗口复用，预览匹配显示器分辨率，OCR 继续读取原图。
- 免费文件翻译显示已完成和总段数，便于查看逐段翻译进度。
- 翻译记忆目录修改后立即生效；CSV v2 备份保留配置上下文、创建时间和命中次数，重新导入 v2 备份时不会覆盖较新的同键记录，并继续兼容旧 CSV。
- 完善 Ladle 组件与 UI 实验室：真实界面使用隔离的本地模拟数据，覆盖主界面、阅读模式、迷你翻译、截图、历史与设置；修复 Windows 预览缓存路径，保留显式环境变量配置。拆分后端模块并补充回归测试。

## 下载

- `VanishTrans_0.1.6_x64-setup.exe`：Windows x64 安装包。
- `VanishTrans_0.1.6_x64-setup.exe.sig` 和 `latest.json`：应用内自动更新使用的签名与清单。

本次为 `v0.1.6` 的维护重发。已安装旧 `0.1.6` 的用户需下载新安装包覆盖安装；同版本重发不会触发应用内更新提示。

## 验证

维护版本源码通过 `pnpm check`（364 项前端测试）、`pnpm build`、`pnpm ladle:build` 和 `pnpm check:rust`（235 项 Rust 测试，含格式和 Clippy 检查）。浏览器预览确认阅读模式往返会恢复原译文滚动位置；发布前须确认目标提交通过 GitHub CI 和安装包构建。

本次发布未重新完成真实 Windows 桌面的 DPI、多显示器、快捷键、OCR 与各应用原地替换的全量人工验收。
