# VanishTrans v0.1.4

## 更新内容

- 更新主界面、设置面板、快捷翻译窗口与悬浮岛的深色视觉，内置 Inter 和 Noto Sans SC 字体及 SIL OFL 许可。
- 悬浮岛可直接查看、复制译文，并将原文、译文和翻译方向带回完整工作区，无需再次发起翻译。
- 译文快照绑定已完成的请求；新请求和取消操作会使旧结果失效，文件结果不会误用上一条文本译文。
- 改进 Windows 原生窗口拖动：等待鼠标释放和系统移动循环结束后再恢复悬浮岛过渡，区分点击与实际拖动。
- 改进设置保存反馈、服务配置选择与键盘操作；连接测试会忽略配置变更后过期的结果。
- 兼容合法的 SSE usage-only 数据块，同时继续校验响应错误、文本内容和终止标记。

## 下载

- `VanishTrans_0.1.4_x64-setup.exe`：Windows x64 安装包。
- `vanish-trans.exe`：Windows x64 独立可执行文件。

## 验证

发布候选通过 `pnpm check`（284 项前端测试）、`pnpm build` 和 `pnpm check:rust`（181 项 Rust 测试，含格式和 Clippy 检查）。GitHub 发布流程还要求对应提交通过 CI 和安装包构建。

本次发布未重新完成真实 Windows 桌面的 DPI、多显示器、快捷键、OCR 与各应用原地替换的全量人工验收。
