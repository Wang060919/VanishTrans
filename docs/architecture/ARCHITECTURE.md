# VanishTrans 重构架构图

## 重构前 (Before) - 职责混杂

```
┌─────────────────────────────────────────────────────┐
│  TranslatePanel.tsx (280 lines)                     │
│  ❌ UI + 文件拖拽 + 复制粘贴 + 状态管理              │
└──────────────────┬──────────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────────┐
│  useTranslation.ts (360 lines)                      │
│  ❌ 流式翻译 + 文件解析 + 批处理 + 请求管理          │
└─────────────────────────────────────────────────────┘
```

**问题**:
- 单个文件职责过多，难以理解和维护
- 缺少纯函数工具，难以测试
- AI 难以快速理解代码意图

```

   │
   ▼
[TranslatePanel] ──► onTranslate(text)
   │                      │
   │                      ▼
   │              [useTranslation]
   │                      │
   │         ┌────────────┼────────────┐
   │         │            │            │
   │         ▼            ▼            ▼
   │   [doTranslate] [doTranslateStream] [doTranslateFile]
   │         │            │            │
   │         │            │            └──► [useFileTranslation]
   │         │            │                       │
   │         │            └──────────┐            │
   │         │                       │            │
   │         ▼                       ▼            ▼
   │    Tauri API              [handleStreamChunk] [parseSrt/parseJson]
   │         │                  [handleStreamDone] [translateBatch]
   │         │                       │            │
   │         └───────────┬───────────┴────────────┘
   │                     │
   │                     ▼
   │              [textUtils] ◄─── 纯函数验证
   │                     │
   │                     ▼

   │                     │
   │                     ▼
   └◄────────── 更新 State (outputText, loading, etc.)
```

## 关键指标对比

| 指标                    | 重构前       | 重构后       | 改进      |
|-------------------------|--------------|--------------|-----------|
| **最大文件行数**        | 360 行       | 240 行       | ↓ 33%     |
| **职责数量 (单文件)**   | 5-7 个       | 1-2 个       | ↓ 70%     |

| **可测试模块数**        | 2 个         | 7 个         | ↑ 250%    |

## 重构收益

### 🎯 可维护性
- 每个文件只做一件事，修改不影响其他模块
- Bug 定位更快，影响范围更清晰

### 🧪 可测试性
- 纯函数可独立单元测试
- Mock 依赖更简单

### 🤖 AI 友好性
- 文件长度适中 (< 250 行)
- 职责清晰，命名语义化
- LLM 可快速理解代码意图

### 🚀 可扩展性
- 新增功能只需增加新的 hook 或工具函数
- 不会影响现有代码
